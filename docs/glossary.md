=================================================
        SECURITY MONITORING PROJECT
               KEY TERMS
=================================================

Authentication - Verifying a user's identity

Authorization - Determining what a user can access

Brute-force Attack - Repeatedly guessing passwords

IP Address - Address identifying a network interface

Source IP - IP address from which network activity originates

SSH - Secure remote access protocol

Security Log - Record of system or security activity

SIEM - Security Information and Event Management

IOC (Indicator of Compromise) - Evidence that suggests a system may have been compromised

Threat Detection - Identifying potentially malicious activity

Incident Response - Process of handling security incidents

False Positive - Legitimate activity incorrectly flagged as suspicious

MFA (Multi-Factor Authentication) - Security method requiring multiple forms of verification

JSON (JavaScript Object Notation) - Structured data interchange format

CSV (Comma-Separated Values) - File format used to store tabular data
